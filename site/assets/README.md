- `avatar.jpg` — portrait used in the Contact section. Downloaded from Abdullahi Abdi's

  resized to 208×208 and re-encoded as JPEG (quality 82) for size. Square crop; keep it
  square if you replace it.

**No stock photography is bundled.** The design brief prefers real product screenshots and
licensed editorial stock images; no stock was used because a license could not be
confirmed. Instead, product proof is a rendered terminal panel and the editorial moment is
an original inline SVG (both in `index.html`). If you add licensed images, store them here
as AVIF/WebP with `width`/`height` set in the markup, `loading="lazy"` below the fold, and
a credit note here.
