Turn a crowded inbox into a system you can understand.

GWS for Dummies lets you tell an AI coding agent what you want in plain English. It uses the Google Workspace CLI to label mail, create Tasks and Calendar events, and prepare useful recaps without sending, trashing, or deleting anything.

Docs

Set up in three steps.

01  Install

Install the Google Workspace CLI and clone the project.

npm install -g @googleworkspace/cli
git clone https://github.com/Mulla759/GWSforDummies.git && cd GWSforDummies

02  Authenticate

Sign in to your own Google account. The runbook covers creating the OAuth client first.

gws auth login -s "gmail,tasks,calendar"
Need the OAuth client step?

The agent runbook walks through creating a free Google Cloud project, enabling the Gmail, Calendar, and Tasks APIs, and placing client_secret.json. Open the full runbook

03  Ask your agent

Describe what you want in plain English.

gws-do "triage my inbox"

Safety model

Reads and labels. Never sends, trashes, or deletes.
