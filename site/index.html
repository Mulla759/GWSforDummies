GWS for Dummies — email triage made easy

A layman-friendly Gmail triage toolkit. You type plain English — like "triage my inbox and label everything" — and a small team of AI sub-agents drives the Google Workspace CLI (gws) against your own Google account. It labels mail, turns action-required mail into Tasks and Calendar events, and can run a nightly labeler. It reads and labels, but never sends, trashes, or deletes.

What it does

01 / triage

Inbox triage & labeling

Security-scans each message, figures out who the sender is and what it says, then applies a clean label taxonomy.

02 / act

Tasks & Calendar from email

Turns action-required mail into Google Tasks entries and Calendar events, with IDs, links, and undo notes.

03 / recap

Weekly digest

A read-only summary of the last seven days: meetings, unread email count, and how much mail got labeled.

04 / autopilot

Nightly labeling

A deterministic sender-to-label script runs nightly (locally or on GitHub Actions) and is idempotent.

Quickstart

# clone, set up, log in, go
git clone https://github.com/Mulla759/GWSforDummies.git && cd GWSforDummies
./setup.sh
gws auth login -s "gmail,tasks,calendar"
gws-do "triage my inbox"
